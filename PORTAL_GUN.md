# Портал-ган — 17.09.2026

Запуск: `Play.cmd`. Редактор: `OpenEditor.cmd` → Play.
Оба запускают новую карту `/Game/Maps/PortalGunLab`.

| Клавиша | Действие |
|---|---|
| ЛКМ | Поставить/перенести синий портал |
| ПКМ | Поставить/перенести оранжевый портал |
| Q | Убрать синий |
| E | Убрать оранжевый |
| X | Убрать оба |
| WASD / мышь / Space | Движение / обзор / прыжок |
| R | Вернуться к старту, оставив порталы |

Стреляйте в белые вертикальные панели. Установка мгновенная, дальность 50 м.
Первый портал отображается цветной закрытой поверхностью. После установки второго
оба проёма открываются: видна другая часть комнаты, работает проход и рекурсивное изображение.
Новый выстрел того же цвета переносит соответствующий портал, закрывая прежнее отверстие.
При ошибке прицеливания существующая пара сохраняется; причина показана на экране.

Поддерживается один портал на панель. Пол и потолок не принимают выстрелы.
Портал нельзя перенести/удалить, пока персонаж находится близко к активному проёму:
отойдите от стены, чтобы не оказаться внутри восстановленной коллизии.
Модель оружия и эффект выстрела пока технические, без финального арта и звука.

## Реализация

- `PortalGun.cpp/.h`: компонент оружия, HUD, PortalWall-панель.
- Панель содержит отдельную поверхность прицеливания и до четырёх блоков стены.
  Проход — реальное отверстие в геометрии и коллизии, не отключение всей стены.
- Проверяются лицевая сторона, размеры всей рамки, место перед проёмом и занятость панели.
- Повторно используются два Gate actor, без создания новых render targets на каждый выстрел.
- При переносе сбрасывается история положения персонажа и камер захвата.
- Оружие скрыто в SceneCapture, поэтому не заслоняет изображение внутри порталов.
- Старый PortalLab и его тесты сохранены отдельно. На нём портал-ган не активируется.

## Проверено

Сборка UE 5.7.2 Development Editor успешна. Автоматический игровой тест с GPU-рендерингом
1920×1080 и лимитом 60 FPS: **31 проверка, 0 ошибок, 2 прохода**.
Скорость при проходах 600 → 600 см/с; расхождение позиции камеры — 0 см.

Проверены установка из направления взгляда, связывание, проход капсулы через обе стены,
отказ на полу и краю панели, препятствие сбоку от центрального луча, сохранение портала
при неверном выстреле, перенос на другую стену, восстановление старой стены, удаление
одного цвета, удаление обоих, повторная установка и запрет закрытия проёма на персонаже.
