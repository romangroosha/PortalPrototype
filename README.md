# PortalPrototype — основа одиночной игры / UE 5.7

Игровая камера от первого лица, порталган, манекен Manny и испытание с кубиком, кнопкой и выходной дверью.

Архитектура новых уровней и параметры объектов: [AUTHORING.md](AUTHORING.md). Полная цель и оставшаяся работа: [GAME_FOUNDATION.md](GAME_FOUNDATION.md). Вторая карта для проверки независимых объектов запускается через `PlayFoundation.cmd`.

## Запуск

Дважды щёлкните `Play.cmd` для игры или `OpenEditor.cmd` для редактирования.
Карта по умолчанию: `/Game/Maps/LevelMenu` — меню выбора уровня. ЛКМ запускает выбранную карту; колёсико мыши и полоса справа прокручивают список. При наведении строка подсвечивается, курсор меняется на руку.
Список автоматически включает только карты из Content/Maps и её подпапок, кроме самого меню. Новые сохранённые карты в этой папке появляются при следующем открытии меню. Для одинаковых названий показан путь. В упакованную игру автоматически включаются карты из Content/Maps и их зависимости.
Лаунчеры используют локальный файловый DDC вместо Zen-сервиса.

WASD — движение, мышь — обзор, Space — прыжок. ЛКМ/ПКМ ставят синий/оранжевый портал на белых панелях. F берёт и отпускает кубик. Q/E удаляют отдельный портал, X — оба. R перезапускает испытание.

Доберитесь до кубика через порталы, принесите его в основной зал и оставьте на оранжевой кнопке. Пройдите через открывшуюся дверь до конца коридора. Кубик в руках кнопку не активирует.

## Ограничения прототипа

Один локальный игрок и одна создаваемая оружием пара; авторские пары могут сосуществовать с ней. PortalWall поддерживает стену, пол, потолок и наклон. Взаимодействие и удержание проходят через цепочку пар. Мультиплеер и стрельба порталганом через порталы пока не поддержаны. Рекурсивный вид ограничен 3 уровнями по умолчанию. Manny виден в камерах порталов; основная камера остаётся от первого лица. Порталган сохраняет прежнюю модель-прототип из примитивов. Полный список оставшейся работы — GAME_FOUNDATION.md.

Для проверки новых ориентаций запустите `PlayTraversal.cmd`; автоматические проверки — `RunTraversalAudit.ps1`. Настройки переиспользуемых элементов описаны в AUTHORING.md.

`Scripts/create_puzzle.py` пересоздаёт новую карту PortalPuzzle: перед запуском сохраняйте её ручные изменения отдельно.
