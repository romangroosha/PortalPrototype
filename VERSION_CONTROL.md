# Версии проекта

Перед сохранением версии нажмите Save All в Unreal Editor. Затем запустите
SaveVersion.cmd и введите короткое описание изменений (Enter — дата и время).
Скрипт добавляет все изменения проекта, включая удаления, и создаёт коммит.
Не помещайте пароли, токены и личные файлы в папку проекта.

Ассеты .uasset и .umap хранятся через Git LFS. Генерируемые каталоги исключены
через .gitignore. Локальная история находится в .git: не удаляйте эту папку.
Локальная история не защищает от потери диска. Автоматического расписания нет.

После создания пустого приватного репозитория GitHub подключите его из папки
проекта (замените URL на адрес своего репозитория):

```powershell
git remote add origin URL
git push -u origin main
```

После подключения origin SaveVersion.cmd также отправляет версии на сервер.
При ошибке отправки локальный коммит сохраняется; повторите запуск для отправки.
Тяжёлые ресурсы в каталогах Content/**/Meshes, Mesh, Models, Textures и Texture
исключены из новых версий, как и пересоздаваемые *_BuiltData.uasset. Карты,
блюпринты, материалы, код, конфигурация и скрипты сохраняются. Новые тяжёлые
ресурсы размещайте в таких каталогах; файлы в других каталогах попадут в Git.
Не размещайте собственные блюпринты или карты внутри исключённых каталогов.

На новом компьютере нужно отдельно восстановить модели и текстуры в прежние
пути Content, иначе использующие их уровни и блюпринты будут иметь недостающие
зависимости. Исходные наборы: 3Dfruit_Particle, Characters, DrapEffet,
Fantasy_Props, Isometric_World, PLATFORMER_StylizedCubeWorld_Vol1, Underwater.
Первый полный снимок оставлен только локально в ветке local-full-backup;
не отправляйте её командой push --all, если не хотите загрузить все ресурсы.

Посмотреть историю: `git log --oneline`. Для восстановления старой версии лучше
сначала сохранить текущие изменения и выбрать нужный коммит, не удаляя историю.
